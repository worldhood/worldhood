# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Be kind, assume good faith, and keep discussion about the work.

Report unacceptable behaviour privately to the maintainers (use GitHub's private security advisory form on this repository, or message the maintainer, Lasse, on [LinkedIn](https://www.linkedin.com/in/lassesaari/)).
Reports are handled confidentially.
